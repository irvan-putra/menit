Menit on the web

Menit on Android estimates how much phone time goes to AI apps. A browser cannot read your phone's usage, so this page is a manual companion: type in minutes you read from Digital Wellbeing and see the same AI / "may include AI" split.

Phone-only part: automatic measurement needs Android's Usage access and only works in the Android app. This page never measures anything by itself. Nothing is uploaded: entries stay in this browser (localStorage). Clearing browser data erases them, so use Export.

Add minutes

Android: Settings → Digital Wellbeing → Screen time → pick a day. Adding the same app and day again replaces it.
